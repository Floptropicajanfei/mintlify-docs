<Update label="04/03/2026">
  ## V1.2

  <Warning>
    We recommend all users to update their board to the newest version for the best performance, any older versions will no longer receive support.
  </Warning>

  ### Added

  - Chronos now supports Firefli
  - Chronos now supports Planetary
  - Trello co-host parsing from card descriptions.
  - Co-hosts now appear on all boards
  - Users can now zoom into the board by clicking on the bottom of a board, users can move or click any button and the camera goes back to them.
  - Sessions will now only display if claimed (configurable)
  - The status of each session (how long until it begins) now displays the hour and minutes.
  - Added new errors and help for configuring newly added features

  ### Removed

  - MergeSources was removed from config
  - Duration of session / event has been removed
  - The mapping section from the config has been removed

  ### Fixes

  - The status no longer disappears and reappears when boards refresh themself
  - Bugs fixed
</Update>
